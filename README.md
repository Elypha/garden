# Garden

A [Scoop](https://scoop.sh) bucket to hold my personal apps and curated community apps.

```powershell
scoop bucket add garden https://github.com/Elypha/garden
scoop install garden/<app_name>
```

## Apps

| App | Description |
| --- | --- |
